Technical Challenge (Problem)

Supporting 7,000+ simultaneous personnel across Saigon Newport Corporation (SNP) from internal web portals, mobile apps, and MS Office desktop extensions.

Architectural Solution

Connected via secure HTTPS with a persistent WebSocket channel to receive instant real-time broadcasts as document stages advance across approval workflows.

Measured Impact

Notification latency < 150ms; eliminated 90% of wasteful HTTP polling traffic to servers.
